Contoh blog sederhana dengan box model

Box model menggunakan model yang dipakai untuk menampilkan elemen html di browser. model ini akan memudahkan kita mengatur ukuran, posisi, dan poperti lainya.

Dengan memahami box model, kita akan mudah mengatur space pada element. Ini berguna dalam membuat layout supaya terlihat rapi dan estentik.
